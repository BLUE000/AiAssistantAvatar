# 意思決定記録: 異常終了 (Crash) 原因の検証および RateLimitTabWidget 再利用化リファクタリング

## 実施日
2026-08-01 (19:46 JST)

## 根本原因 (Empirical Evidence)
- `tmp/app_debug.log` の 200,341 行目付近の解析により、設定保存・変更イベント時にクラッシュが発生していることを確認。
- `RateLimitTabWidget::updateProviderCard()` 内で 1 秒タイマーのたびに `card.itemsLayout` 内の `QWidget` や `QProgressBar` などの GUI ウィジェットを毎秒 `delete` / `new` していたため、Qt イベントループとの競合でヒープ破壊・クラッシュを引き起こしていたことが原因。

## 永久対策・改修内容
- `RateLimitTabWidget` 内の UI コンポーネントを**再利用方式 (Widget Reuse)** へリファクタリング。
- ウィジェットの生生成は初回のみ行い、毎秒のタイマーでは `setText()` や `setValue()` で値を更新するだけの安全な構造へ刷新。
