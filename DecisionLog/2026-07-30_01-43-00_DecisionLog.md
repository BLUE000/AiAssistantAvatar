# 意思決定記録: HuggingFace/OpenRouter/さくらAI のモデル適正化・Web検索(Tavily)共通連携・会話履歴内部タグ除去の不具合修正

## 実施日
2026-07-30

## 背景・課題
1. **HuggingFace**: `mistralai/Mistral-7B-Instruct-v0.3` が Chat エンドポイント非対応のため `HTTP 400 (不正なリクエスト形式)` が発生。
2. **OpenRouter / HuggingFace / さくらAI**: Tavily API キーが供給されているにも関わらず、リクエスト JSON への `tools` 付与および Tavily Web 検索ハンドラ (`executeSearch`) が未実装でWeb検索機能が不発。
3. **さくらAI 等**: 会話履歴 `history` に付加されている内部制御タグ (`[Direct]` や `[Twitch]`) が除去されずに送られ、AI の応答本文末尾に内部ログテキストが漏れ出す現象が発生。

## 意思決定内容
1. **HuggingFace / OpenRouter モデル選出・適正化**:
   - `HuggingFaceAIClient` のデフォルトモデルを Chat 対応モデル `Qwen/Qwen2.5-Coder-32B-Instruct` に変更し、`/v1/models` での動的選出を追加。
   - `OpenRouterAIClient` のデフォルトモデルを `google/gemma-2-9b-it:free` に設定。
2. **Web検索 (Tavily) 共通連動の実装**:
   - `HuggingFaceAIClient`, `OpenRouterAIClient`, `SakuraAIClient` に `tools` (web_search) 付与、`tool_calls` 解析、および `m_searchManager->executeSearch()` 連携を完全実装。
3. **会話履歴内部タグのクリーンアップ**:
   - `history` の送信メッセージから `[Direct] ` や `[Twitch] ` などの内部プレフィックスを自動除去して送信する処理を追加。

## 影響範囲
- `src/ai/huggingface_ai_client.h` / `cpp`
- `src/ai/openrouter_ai_client.h` / `cpp`
- `src/ai/sakura_ai_client.h` / `cpp`
