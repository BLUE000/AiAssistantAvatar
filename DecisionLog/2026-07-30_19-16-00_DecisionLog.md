# 意思決定記録: さくらAI (llm-jp-3.1) 向け参考情報 (RAG) の User ロール挿入実験

## 実施日
2026-07-30

## 背景・課題
- 実送受信ログ `tmp/app_debug.log` の検証により、さくらAI (`llm-jp-3.1-8x13b-instruct4`) は System ロール内に長い参考テキストを挿入しても効果がなく、モデルの拒否フラグ（「アクセスできません」）を発動させてしまうことが判明した。

## 意思決定内容
1. **RAG コンテキストの User ロールへの変更**:
   - `SakuraAIClient` において、Tavily 検索結果を System メッセージではなく **User メッセージ (`{"role": "user", "content": "【参考情報】..."}`)** として質問プロンプトの直前に挿入する。
2. **極小かつ明瞭な形式への整形**:
   - 余計な説明を省き、「【参考情報】\n大阪市の天気: 晴れ、最高33℃、最低27℃」のように超簡潔な箇条書きで User ロールから手渡し、モデルが素直に情報を読み取れるか検証する。

## 影響範囲
- `src/ai/sakura_ai_client.cpp`
