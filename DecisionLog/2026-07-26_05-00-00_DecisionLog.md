# 意思決定ログ (Decision Log)

## 日時: 2026-07-26 05:00:00

### 変更の理由 (Why)
不特定多数のユーザーやコミュニティが作成した Markdown ナレッジファイルを安全かつ安定して読み込み・実行できるようにするため、以下の新ナレッジベースアーキテクチャの導入と 5 種仕様書（Requirements, BasicDesign, DetailedDesign, UnitTest, SystemTest）の改訂を行う。

1. **インデックス管理 (`knowledge_index.json`)**:
   - `knowledge/` ディレクトリ内の Markdown ファイルを自動スキャンし、トリガー・優先度・モード等のメタデータを抽出して構造化したインデックスを自動生成・管理する。
2. **決定論的優先度制御 (Priority)**:
   - 複数ファイルで同一のトリガー（例: 「占い」）が重複した場合、固定された優先順位 (`priority`) で実行対象を解決し、不具合とランダム選出の混同を防止する。
3. **トリガー安全起動条件 (誤爆防止)**:
   - 単なる単語の出現ではなく、「アバター名」または「ウェイクワード」とセットで呼び出された場合のみトリガーを発火させる。
4. **構文エラーチェッカー (バリデーション ＆ 診断通知)**:
   - フォーマットエラー（テーブル列数不一致、必須見出し欠損等）のあるファイルは読み込みから自動除外し、ナレッジ管理UIやログに該当ファイル・行数・エラー内容を「診断レポート」として可視化する。

- `doc/SystemTest.md`
