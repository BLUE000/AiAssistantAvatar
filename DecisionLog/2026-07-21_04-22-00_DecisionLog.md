# Decision Log: 2026-07-21 04:22:00

## 変更の概要
- **対象**: ディレクトリ構成 (pic/ フォルダ配下) および アバタースキン選択・同期表示機能 (F-23)
- **フェーズ**: 要件定義・基本設計・詳細設計

## 変更理由 (Why)
- 今後の複数アバタースキン（テーマ・衣装・キャラクター追加）への柔軟な拡張に対応するため、`pic/` 直下に混在していたアセット群（画像・`avatar_settings.json`・`avatar_obs.html`）をスキン識別用サブフォルダ（`pic/FishEatCatSkin/`）配下に分離・整理する必要が生じた。
- アプリ本体画面（UI）とOBS配信画面で表示されるアバターが異なるスキンになる不一致を防ぐため、設定画面で選択されたスキンをアプリUIとOBS配信画面の双方で常に100%統一・同期表示する仕様に策定した。

## 決定事項
1. **ディレクトリ構造**: `pic/` 直下に各スキン識別フォルダ（例: `FishEatCatSkin`）を作成し、アセット一式を格納する。
2. **設定画面 UI (AvatarWindow)**: 設定タブにアバタースキン選択（QComboBox）を追加し、`pic/` 配下のスキンフォルダを動的に検出する。
3. **完全同期表示**: 設定されたスキンに応じ、アプリ本体のアバター表示エンジンおよび OBS HTTP サーバーの Document Root を一括更新する。
