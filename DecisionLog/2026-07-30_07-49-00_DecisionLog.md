# 意思決定記録: さくらAI限定における Manager AI 代理回答ルーティングの仕様定義および実装

## 実施日
2026-07-30

## 背景・課題
- さくらAI (`llm-jp-3.1-8x13b-instruct4`) はモデル内蔵の安全性制限ガードにより、Web検索が必要なクエリ（天気・最新ニュース等）に対して「アクセスできません」とお断りを出してしまう。
- ユーザー選択プロバイダの優先原則を守りつつ、さくらAI選択時のみ限定して Manager AI（Groq等）が代理で Web 検索・回答生成を引き受けることで、さくらAI選択時でも天気を 100% 正確にアバター応答させる。

## 意思決定内容
1. **仕様書の拡張更新**:
   - `doc/Requirements.md` / `doc/BasicDesign.md` / `doc/DetailedDesign.md` / `doc/UnitTest.md` / `doc/SystemTest.md` に「さくらAI限定 Manager AI 検索代理回答仕様」を追加定義する。
2. **`AIClientManager` における代理ルーティングの実装**:
   - さくらAI (`sakura`) 選択時に Web検索が必要なクエリ（天気・ニュース等）が入力された場合、`AIClientManager` が Manager AI へ代理ルーティングを行い、Tavily 検索およびアバター回答生成を行わせる。
   - 他のプロバイダ（Groq, OpenRouter, Mistral, Cerebras, HuggingFace）には一切影響を与えず従来動作を維持する。
