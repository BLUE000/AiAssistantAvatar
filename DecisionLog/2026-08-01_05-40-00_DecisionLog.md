# 意思決定記録: レイドシャウトアウト/アナウンスの Twitch Helix API 優先 ＆ IRC フォールバック ハイブリッド送信 (F-22-1) の仕様追加

## 実施日
2026-08-01

## 理由・目的
- ユーザーからのご報告（レイド紹介時に UI や OBS ブラウザソースには吹き出しが表示されるが、Twitch チャットにコメントが投稿されない）を受け、要因調査を実施。
- Twitch IRC サーバーにおける `/announce` および `/shoutout` PRIVMSG 直接送信のサイレントドロップ仕様を解消するため、Twitch Helix REST API (`POST /helix/chat/announcements` / `POST /helix/channels/shoutouts`) による公式カラーバナー優先発火と、失敗時・通常時の IRC 投稿への自動フォールバックを組みあわせた二重ガード（ハイブリッド送信）仕様を構築するため。
