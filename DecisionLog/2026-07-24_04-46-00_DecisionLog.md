## 背景・コンテキスト
- アバタースキン設定、アバター名、名前反応、ウェイクワード、判定モードが異なるグループボックスに分散していたため、「アバター共通・基本設定」への一括集約を決定。
- OBS取り込み表示をローカルファイル絶対パスから HTTP サーバー経由の URL (`http://localhost:<ポート>/avatar_obs.html`) 表示に変更し、HTTPサーバーを常時自動ONとして誤操作防止と2PC配信・CORS制限回避を図る。
- TaskFlow API 連携設定を Discord 連携から独立させ、「TaskFlow 連携設定」グループボックス（有効化チェックボックス＋任意可変API URL）を新設。また、TaskFlow連携有効時は Discord に限らず Twitch チャットや UI 入力からの予定照会にも自動応答可能とする。
