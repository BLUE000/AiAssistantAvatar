# 決定ログ (Decision Log) - 2026-08-05 21:02:00

## 変更の概要 (Summary)
HTTP サーバー (`ObsHttpServer` @ 58082) に `/stt` および `/stt_input` エンドポイントを完全実装。ブラウザからのアクセス時に 404 エラーとなる現象を解消し、GET (`?text=...`) または JSON POST による外部音声認識テキスト注入機能を実現した。

## 理由 (Why)
- **現状の問題**:
  - `http://192.168.0.45:58082/stt` にアクセスした際、`ObsHttpServer` に `/stt` のルートハンドラが未実装だったため、ファイルを探しに行って `{"error":"Not Found","message":"File not found","status":404}` のエラーが返答されていた。
  - `http://localhost:58082/stt` で「接続拒否」となるのはアプリ未起動またはプロセス停止時であった。
- **対処内容**:
  1. `ObsHttpServer::handleRequest` に `/stt` および `/stt_input` のエンドポイント判定を追加。
  2. GET `?text=...` または JSON POST `{"text":"..."}` を受けると `sttTextReceived` シグナルを発火し、`CoreModule::on_notify_events` へつないで AI 応答を直接起動する。
  3. テキスト指定無しの GET アクセス時は、`200 OK` JSON (`{"status":"ok","endpoint":"/stt", ...}`) を返し、接続チェックを可能とした。
  4. 単体テスト `ObsHttpServerTest.SttEndpointTest` を追加し 100% PASSED。
  5. コミット `243c749` の Push、公式認定クリーン・リリースビルド生成、および `dist/AiAssistantAvatar_Release.zip` (35.8 MB) への格納完了。
