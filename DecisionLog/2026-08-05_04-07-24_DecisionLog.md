# DecisionLog — 2026-08-05 04:07:24

## 決定事項：saveSettingsFromUI における旧 UI コントロールへの Null Pointer アクセスの除去

### 背景
実証ログ追跡により、「設定を保存して適用」ボタンおよび「Twitch認証開始」ボタンを押した際、`saveSettingsFromUI()` 内の 1703 行目でアプリケーションが例外出力なしに即座にクラッシュしていることが判明した。

### 原因
レートリミット設定の `RateLimitTabWidget` への一元化に伴い、旧プロバイダ制限設定の UI コントロール（`m_limitProviderCombo`, `m_limitRpmEdit` 等）が削除されヌルポインタ (`nullptr`) になっていた。
しかし `saveSettingsFromUI()` 内に旧 UI コントロールから現在選択値を取得するコードが残っていたため、Null Pointer Dereference (Access Violation) が発生してアプリが即死していた。

### 修正内容
`src/ui/avatar_window.cpp` の `saveSettingsFromUI()` において、`m_limitProviderCombo` 等の旧 UI コントロールに対する Null チェック保護を追加し、ポインタが存在しない場合は安全にスキップするように修復。

### 変更ファイル
- `src/ui/avatar_window.cpp`
