## 本実装内容
1. **Release ビルドでのダミー AI 排除**:
   - `src/ui/avatar_window.cpp` において、全プロバイダのチェックボックスが外されている場合、Debug ビルドでは `"dummy"`、Release ビルド（`#ifndef QT_DEBUG`）では `"auto"` モードを選択・保存するよう実装。
2. **レートリミット残量判定メソッド (`selectBestAvailableClient`) の実装**:
   - `RateLimitTracker` に `selectBestAvailableClient()` メソッドを新設。現在利用可能 (`available == true`) で、かつ RPM/RPD の残容量（使用枠）が最も多いプロバイダを評価・選定する。
3. **全 API キー未設定ガード**:
   - 全プロバイダの API キーが未設定（空）の場合、外部送信を行わず「*APIキーが設定されていません。設定画面で設定してください*」と案内を即座に通知する。
4. **レートリミット全枯渇時の二分岐通知**:
   - 利用可能な AI が 0 件となった場合、最長リセット時間を算出し、未設定キーの有無に応じて二分岐（パターン A: 残時間 ＋ 未設定キー取得案内、パターン B: 残時間のみ表示）の親切なメッセージを生成・通知。
5. **CTest 検証**:
   - `UT-ROUTER-04` を含む全テストケースが 100% PASS することを確認。
