# 意思決定ログ - Twitchコメント翻訳機能（Option 2）の実装およびドキュメント・テスト・パッケージ更新

## 日時
2026-06-25 00:56:00 (JST)

## 1. 意思決定の背景と目的

- **背景**:
  - ユーザーから Twitch コメントの翻訳コマンド機能（オプション2: `!ai trans [言語指示子] [テキスト]` で翻訳結果のみを返し、履歴を汚染しない機能）の実装要望がありました。
  - さらに、Mistral AI の Web 検索機能（Function Calling）における HTTP 400 (Bad Request) エラー（2回目のリクエストボディに `tools`/`tool_choice` が残っていた問題）の修正と、ログ出力機能の強化、および仕様書の同期更新が必要でした。
- **決定**:
  - `AIClientManager` において `trans` プレフィックスによる翻訳コマンドを検出し、過去の履歴やコンテキストに影響されず（空にして送信）、かつ結果の履歴蓄積やログ保存をバイパスする仕組みを実装する。
  - AI が自分自身の翻訳コマンドの使い方を英語・日本語等で尋ねられた際に正しく答えられるよう、システムプロンプトに説明を追加する。
  - Mistral AI クライアントにおける Function Calling 時のモデルを `mistral-small-latest` に変更し、2回目のリクエストから `tools`/`tool_choice` を除去し、かつ API レスポンス形式を JSON 文字列として正しくラップするよう修正する。
  - 変更内容に合わせて、要件定義書 (`Requirements.md`)、基本設計書 (`BasicDesign.md`)、詳細設計書 (`DetailedDesign.md`)、単体試験仕様書 (`UnitTest.md`)、結合試験仕様書 (`IntegrationTest.md`)、および総合試験仕様書 (`SystemTest.md`) を同期更新する。
  - 新機能の自動テストケース (`TranslationCommandTest`) を追加して検証し、Release ビルドを再実行した上で、最新の配布用 ZIP パッケージを再パッケージングする。

---

## 2. 影響範囲と対策

- **AI 連携**:
  - 翻訳コマンド `trans` 実行時、会話履歴を一時的に空にしてリクエストを送信するため、翻訳の正確性が向上し、直前のマスコット風キャラクター設定に引きずられないようにしました。
  - 翻訳結果を会話履歴（メモリ）やセッションログ（暗号ファイル）に保存しない（バイパスする）ため、メモリバッファの汚染や自動リセットカウントの増加を防ぎます。
- **Web検索（Function Calling）**:
  - API モデルを `mistral-small-latest` に変更し、2回目送信時のボディ不整合を解消したことで、HTTP 400 エラーが発生しなくなり、正常に検索に基づいた回答が返るようになりました。
- **ドキュメント・試験**:
  - 単体、結合、総合（システム）試験仕様書すべてに翻訳コマンド機能の項目が追加され、トレーサビリティが確保されました。
