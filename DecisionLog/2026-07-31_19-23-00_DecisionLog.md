# 意思決定記録: TaskFlow API URL デフォルトハードコード撤廃および未設定時安全ガードの仕様追加

## 実施日
2026-07-31

## 理由・目的
- ユーザーからのご指摘（TaskFlow はマルチユーザー非対応であり、個人のサーバー URL "https://streamers-tool.sakura.ne.jp/TaskFlow/..." をコード内にデフォルト値として保持すると、他ユーザー使用時に他人の予定が読み込まれてしまうプライバシー・セキュリティ問題が発生する）を受け、デフォルト URL のハードコードを撤廃し、`m_taskFlowApiUrl` が空の場合は安全に通信を即時キャンセルする仕様に変更するため。

## 改修ドキュメント
1. `doc/Requirements.md`: F-20 等の TaskFlow 連携要件に「デフォルト URL ハードコード非保有・未設定時通信スキップガード」を追記。
2. `doc/BasicDesign.md`: TaskFlow 連携コンポーネント部に本安全仕様を追記。
3. `doc/DetailedDesign.md`: 12.3 節などの TaskFlow 取得シーケンスに URL 未設定ガード分岐を追加。
4. `doc/UnitTest.md`: `UT-TASKFLOW-01` 単体テスト項目（URL 未設定時に通信が発生せず空を返却すること）を追加。
5. `doc/SystemTest.md`: `ST-F20-02` システムテスト項目を追加。

## 影響範囲
- `doc/` 配下の全仕様書・設計書
- `src/ai/ai_client_manager.cpp` (`fetchSchedules` 内)
