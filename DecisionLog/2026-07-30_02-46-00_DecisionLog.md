# 意思決定記録: AIプロバイダ切り替え時のマルチスレッド所有権例外（QNetworkAccessManager スレッド不一致）によるクラッシュ防止修正

## 実施日
2026-07-30

## 背景・課題
- 設定画面等で AI プロバイダを **OpenRouter** 等に切り替えた際、`QNetworkAccessManager` のスレッド所有権と現在の呼び出しスレッド (`QThread`) が一致せず、`QObject: Cannot create children for a parent that is in a different thread` 警告および `QWaitCondition` 破壊に伴うクラッシュが発生していた。

## 意思決定内容
1. **ネットワークマネージャのスレッド所属動的バインド**:
   - `OpenRouterAIClient`, `HuggingFaceAIClient`, `SakuraAIClient`, `GroqAIClient`, `MistralAIClient`, `CerebrasAIClient`, および `TavilySearchProvider` の通信開始処理 (`sendRequest`, `search`) 直前にて、`m_networkManager->thread() != QThread::currentThread()` をチェックし、スレッドが異なる場合は `m_networkManager->moveToThread(QThread::currentThread())` を実行して安全に同調させる。
2. **スレッド破棄時の安全性向上**:
   - スレッドが破棄または再接続される際の `deleteLater()` の適用と NULL チェックを徹底。
