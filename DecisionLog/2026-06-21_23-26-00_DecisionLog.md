# 意思決定ログ (2026-06-21 23:26:00)

## Twitch認証設定保存バグ、チャット無反応バグ、ウインドウ見切れバグ、およびDuckDuckGo検索ボット判定ブロックの修正
* **背景・理由**:
  - Twitch認証を行った後に設定を保存してもチャットに反応しないバグが報告された。
  - 調査および追加したログ（`app_debug.log`）の解析結果により、以下の原因が複合して発生していることが判明した：
    1. **直接ファイル書き込みによるスレッド競合（Windows共有違反）**: `TwitchReader` スレッドが非同期で `local_settings.json` を開いてトークンを直接保存しようとする動作が、UI（メイン）スレッドの保存動作と重なり、共有違反を起こしていた。
    2. **UIスレッドでのトークンクリア**: UI側の `saveSettingsFromUI()` で `m_twitchOAuthToken` メンバ変数が正しく同期されておらず、設定上書き時にトークンがクリアされていた。
    3. **HTTP GETリクエストの未実行（本質的なバグ）**: `TwitchReader::fetchChannelName` 内で `QNetworkAccessManager` と `QNetworkRequest` は構築されていたものの、実際にリクエストを発行する `manager->get(request)` の呼び出しが抜け落ちていた。そのため、認可コールバック受信後に Helix API からチャンネル名を取得する処理が一度も実行されず、UIスレッドへの `SettingsUpdated` イベント通知自体が未発生のままフリーズしていた。
    4. **IPv6 localhost接続拒否問題**: 一部環境でブラウザが `localhost` を IPv6 (`::1`) に解決してアクセスしてきた際、アプリの一時サーバーが IPv4 (`127.0.0.1`) のみで待ち受けていたため接続拒否され、認可自体が完了しない可能性があった。
  - さらに、上記の修正に付随し、「**起動時のウィンドウ位置が画面下部から半分以上めり込み、最初からモニターで見切れてしまっている**」という問題が報告された。
    - **原因**: 以前のアバター単体モード時代の名残りである `m_desktopTargetPos = QPoint(..., height - 150)` という初期位置計算ロジック（画面下部にアバターの足元を置くための計算）のままであった。幅 750 × 高さ 480 の大型化した通常ウィンドウでこれを行うと、アンカー調整の結果、画面下部にウィンドウの半分以上がはみ出して（見切れて）しまっていた。
    - **解決策**: デフォルトの目標位置（`m_desktopTargetPos`）を画面下部ではなく**画面中央（`height / 2`）**に変更し、起動時にウィンドウ全体がモニター中央付近に綺麗に収まり、見切れないように修正した。さらに最初の配置時に位置を `m_lastWindowPos` にキャッシュし、2回目以降の状態変化ではウィンドウ自体の位置を瞬間移動させないようにした。
  - また、Twitchチャットで「日本の首相 2026年6月 教えて」と質問した際、最新情報をWeb検索せず、2024年の古い学習データを元に回答してしまう問題が確認された。
    - **原因**: 診断ログを確認したところ、Tavily API キーが未設定の場合のフォールバック先である **DuckDuckGo 検索で `Blocked or Rate Limited.` (Forbidden 403) が発生**し、検索結果が空で返されていた。これは、`QNetworkAccessManager` による簡易的なHTTPリクエストが、DuckDuckGo側のアンチボット保護フィルタに「自動化スクリプト」として検知されたため。
    - **解決策**: ボット検知を回避するため、リクエストヘッダーに最新の User-Agent およびブラウザ特有の `Sec-Fetch-*` ヘッダーなどを追加して、正規の Chrome ブラウザからのアクセスを精緻に偽装するように修正した。
* **変更内容**:
  - `TwitchReader::fetchChannelName` の最後に `manager->get(request);` を追加。
  - `TwitchReader::startOAuthServer` にて、`QTcpServer::listen` のアドレスを `QHostAddress::Any` に変更。
  - `TwitchReader` からの直接のファイルI/Oを廃止し、UIスレッドからの自動保存に一本化。
  - `AvatarWindow::updateWindowPosition` にて、`m_lastWindowPos.isNull()` による初回配置キャッシュを導入し位置キープ。
  - `AvatarWindow` のコンストラクタにて、起動時初期目標位置 `m_desktopTargetPos` を画面中央に変更。
  - `DuckDuckGoSearchProvider::search` 内で、リクエストに最新 User-Agent (`Chrome/126.0.0.0`) を適用し、`Sec-Fetch-Dest`, `Sec-Fetch-Mode`, `Sec-Fetch-Site`, `Sec-Fetch-User`, `Upgrade-Insecure-Requests` などのブラウザ偽装ヘッダーを追加してボットフィルタをバイパスするように修正。
