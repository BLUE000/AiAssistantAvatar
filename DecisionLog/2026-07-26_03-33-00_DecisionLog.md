# Decision Log - 2026-07-26 03:33:00

## 1. 概要
ユーザー要請に基づき、新規 AI プロバイダとして **HuggingFace**, **OpenRouter**, **さくらAI (Sakura AI)** の 3 種をアプリの AI クライアントエンジンとして統合（F-32）した。

## 2. 決定事項と理由 (Why)

### ① 新規 AI プロバイダ 3 種 (HuggingFace / OpenRouter / さくらAI) の同時選定理由
- **理由**:
  - **HuggingFace**: 世界最大のオープンソース AI コミュニティであり、Llama 3.1, Qwen 2.5, Mistral 等の最新オープンモデルが自前サーバー不要の Serverless Inference API で直ちに利用可能。
  - **OpenRouter**: 多種多様なプロバイダのモデル（無料枠モデル含む）を統一 API キーで呼び出せる集約サービスであり、ユーザーの利便性が非常に高いため。
  - **さくらAI (Sakura AI)**: さくらインターネットの提供する国内高火力 LLM インフラであり、高速かつ安定した日本語モデルの利用が可能であるため。
- **統一通信規格**:
  - 3 プロバイダともに OpenAI 互換の Chat Completions API 規格（`https://.../v1/chat/completions`）を採用しているため、クライアント実装の保守性・共通化が極めて高く、安定した拡張が可能である。

### ② Vプロセスに基づいた仕様書先行更新および C++ 実装 ＆ ビルド
- **理由**:
  - `.ai_rules.md` に定めるルールを遵守し、仕様書先行定義のプッシュ後に C++ クラス (`HuggingFaceAIClient`, `OpenRouterAIClient`, `SakuraAIClient`) を新設。
  - GUI 設定画面 (`AvatarWindow`) に HuggingFace, OpenRouter, さくらAI の個別設定項目（チェックボックス、API Key、Model名）を追加。
  - 単体テスト全 55 件 PASS を確認後、TrustChain 公式認証証明書付きパッケージをビルドした。
