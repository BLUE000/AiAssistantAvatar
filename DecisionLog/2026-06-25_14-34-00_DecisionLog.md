# 意思決定ログ - Web検索（Function Calling）再送信リクエストへの tools/tool_choice 追加

## 日時
2026-06-25 14:34:00 (JST)

## 1. 意思決定の背景と目的

- **背景**:
  - Mistral AI からの指摘として、`on_searchFinished` 内で Mistral API へ送信する2回目（最終回答用）リクエストボディに `tools` 配列および `tool_choice` が含まれていなかった。
  - この欠落により、モデルがツール応答を正しく処理できず Web 検索機能が正常に動作しない問題があった。
  - `m_toolsArray` はメンバ変数として `sendRequest` 時に正しく保存されていたが、`on_searchFinished` での再送信時に使用されていなかった。
- **決定**:
  - `on_searchFinished` 内の再送信リクエストボディに `requestBody["tools"] = m_toolsArray;` および `requestBody["tool_choice"] = "auto";` を追加する。

---

## 2. 影響範囲と対策

- **Web検索（Function Calling）**:
  - 再送信リクエストでもツール定義とツール選択ポリシーが正しく渡されるようになり、Mistral API がツール応答を正常に処理できるようになった。
  - これにより、検索結果を踏まえた最終回答が正しく生成されることが期待される。
- **デバッグログ**:
  - 既存のデバッグログ（`Final Request Body` の出力）により、`tools` と `tool_choice` が含まれているかをログで確認できる。

---
