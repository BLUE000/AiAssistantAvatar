# 意思決定記録: さくらAI向け検索結果ノイズ（URL・メタデータ）除去と『既知の情報』フォーマット化実験

## 実施日
2026-07-30

## 背景・課題
- ログ検証により C++ の RAG 渡しの仕組み自体は完全に正常動作しているが、Tavily の生データに含まれる `URL: https://...` や `[1]` 等の Web 検索用メタデータが残っているため、さくらAIが「検索結果サイトの生データ」と認識し、モデルの定型拒否ルール（「アクセスできません」）を誤発動させていた。

## 意思決定内容
1. **検索結果からの URL・メタノイズ完全除去**:
   - `SakuraAIClient` において、Tavily 検索結果から `http://`, `https://`, `[1]`, `URL:` などの冗長な Web 検索メタデータを正規表現で綺麗に削除・整形する。
2. **『既知の情報』形式でのプロンプト構築**:
   - フォーマットを「【参考情報】\nあなたは以下の情報を既に知っています：\n（ノイズ除去されたテキスト）」に変更し、モデルに「検索結果」ではなく「モデルが元々知っている知識」として自然に認知させて回答させる。

## 影響範囲
- `src/ai/sakura_ai_client.cpp`
