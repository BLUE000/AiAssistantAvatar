# 意思決定記録: ログ分析による問題点の特定（SakuraAIClient内部の旧自前検索処理の残留による二重検索の発見）

## 実施日
2026-07-31

## 検出された問題点
1. **二重検索の発生 (2重 API 呼び出し)**:
   - `AIClientManager` レイヤーで共通事前 RAG 検索が正常実行されているにもかかわらず、`SakuraAIClient::sendRequest` 内に古い自前 Web 検索コード（`needsSearch` 判定および `m_searchManager->executeSearch` 呼び出し）が残留していた。
   - これにより、1回目の検索成功後に `SakuraAIClient` 内部で再度 2 回目の Tavily 検索が実行され、無駄な API コールと3秒以上の応答遅延が発生していた。
2. **二重検索クエリの汚染**:
   - `SakuraAIClient` に渡された 2 回目の検索クエリが、1 回目の検索結果である `【参考情報】...` を含む巨大プロンプト全文になっていた。

## 影響範囲
- `src/ai/sakura_ai_client.cpp`
