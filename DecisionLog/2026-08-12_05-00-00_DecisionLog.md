# DecisionLog: 設定ファイルパス一元化 (Config/local_settings.json) および Twitch 認証時設定再ロードに関する仕様書改修

## 日時
2026年8月12日

## 概要
ユーザーからの指示「まずは仕様書だけお願いします」に基づき、アプリケーション設定ファイル `local_settings.json` の参照・保存先を要件定義書通りの `Config/local_settings.json` に完全固定・一元化し、ルート直下等の古いフォールバック探索の全廃、初回起動時のサンプル自動複製、Twitch 認証開始時の即時同期再読み込み、および単体テスト環境の分離について仕様書およびテスト仕様書の更新を実施した。

## 改修内容

1. **要件定義書 ([doc/Requirements.md](file:///d:/prog/C++/AiAssistantAvatar/doc/Requirements.md#L130))**:
   - `local_settings.json` を含む全設定ファイルの保存先を `Config/` フォルダ配下（`Config/local_settings.json`）に完全固定・一元化（フォールバック全廃）。
   - 初回起動時または非存在時の `Config/local_settings.json.sample` からの自動複製・初期生成仕様を追記。
   - 「Twitch OAuth 再認可」処理呼出時に `Config/local_settings.json` から最新の設定を即座に同期再読み込み（`loadSettings()`）した上で認証を開始する動作要件を明記。

2. **基本設計書 ([doc/BasicDesign/Settings.md](file:///d:/prog/C++/AiAssistantAvatar/doc/BasicDesign/Settings.md#L13))**:
   - 全モジュール（`AvatarWindow`, `TwitchReader`, `DiscordReader`, `AIClientManager`, `main.cpp`）での `Config/local_settings.json` 一元参照設計を明確化。
   - 初回自動生成ロジックおよび単体テスト実行時のテスト専用環境（`test_local_settings.json` 等）への分離方針を明記。

3. **詳細設計書 - Twitch ([doc/DetailedDesign/Twitch.md](file:///d:/prog/C++/AiAssistantAvatar/doc/DetailedDesign/Twitch.md#L58))**:
   - `TwitchReader::on_twitchReauthRequested()` 呼出時に直前に `loadSettings()` を同期的呼び出して `m_clientId` を更新してから Client ID の不在チェックおよび認証サーバー起動を行う詳細シーケンスを追記。

4. **詳細設計書 - UI ([doc/DetailedDesign/UI.md](file:///d:/prog/C++/AiAssistantAvatar/doc/DetailedDesign/UI.md#L73))**:
   - `AvatarWindow::saveSettingsFromUI()` および `loadSettingsToUI()` の対象パスを `Config/local_settings.json` に統一。

5. **単体テスト仕様書 ([doc/UnitTest.md](file:///d:/prog/C++/AiAssistantAvatar/doc/UnitTest.md#L237))**:
   - テストケース（`UT-UI-SAVE-01`, `UT-GREET-01` 等）における対象パスをテスト隔離パス明記へと更新。
   - 新規テストケース `UT-TWITCH-REAUTH-01`（認証直前の `Config/local_settings.json` 同期再ロード検証）を追加。

6. **システムテスト仕様書 ([doc/SystemTest.md](file:///d:/prog/C++/AiAssistantAvatar/doc/SystemTest.md#L54))**:
   - `ST-F5-04`, `ST-F5-05` にて `Config/local_settings.json` からの同期読込・Client ID 保持を明記。
   - 新規テストケース `ST-F5-06`（初回起動時の `Config/local_settings.json.sample` からの自動複製確認）を追加。

## ステータス
仕様書改修完了。ソースコードおよびテストコードの修正は次のステップで実施予定。
