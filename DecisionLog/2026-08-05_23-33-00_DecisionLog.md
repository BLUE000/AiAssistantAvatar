# 決定ログ (Decision Log) - 2026-08-05 23:33:00

## 変更の概要 (Summary)
1. **AI 応答送出遅延 (1秒未満の時差制御) 仕様追加**:
   Groq や外部 AI サーバーへ短時間で連続リクエストが送信され「Bot/不正アクセス」と判定される不具合を防ぐため、AI リクエストおよびマネージャー AI 評価時に 1 秒未満（約 600ms）の送出遅延（時差）を導入。
2. **ブラウザ用 WebSTT 音声入力 ＆ ウェイクワード常時監視 Web 画面 (`http://<IP>:58082/stt`) 仕様確定**:
   `GET /stt` アクセス時に WebSpeech API 対応のマイク音声認識 ＆ ウェイクワード常時監視 HTML ページを返答し、スマホやサブPCからハンズフリーでアバターと声で話せる WebSTT UI を提供。
