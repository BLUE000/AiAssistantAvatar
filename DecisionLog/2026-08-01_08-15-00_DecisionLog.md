# 意思決定記録: Intent判定最適化・検索トリガー精緻化・プロンプト役割分離 (F-16-9) の仕様追加

## 実施日
2026-08-01 (08:15 JST)

## 理由・目的
- 「今日の予定は？」という質問に対して「今日」という単語単体で Web 検索が誤発火し、全国の天気記事が取得され、さらにそれが User メッセージの先頭に直接連結された結果、LLM が天気の質問だと勘違いして会話が噛み合わなくなる不具合を根本解消するため。
- 日時単語単体での Web 検索自動発火を廃止し、明確な目的名詞（「天気」「ニュース」「株価」等）でのみ検索を発火させ、スケジュール関連（「予定」「タスク」等）は Web 検索をスキップする仕様へ変更する。
- 収集された事前データ（Web検索結果、TaskFlow、ナレッジ）を User メッセージへ直接連結せず、System プロンプト領域（`systemInstruction`）へ役割ごとに構造化注入するプロンプト役割分離構成を採用するため。
