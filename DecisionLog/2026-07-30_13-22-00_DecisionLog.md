# 意思決定記録: さくらAI 送信リクエスト JSON 全体ログ出力の追加（RAG構造検証）

## 実施日
2026-07-30

## 背景・課題
- さくらAI (`SakuraAIClient`) へ RAG 検索結果が正しくシステムプロンプト経由で渡されているかを確実に可視化・検証するため、GPT からの依頼に基づき POST 直前の JSON 全体を整形ログ出力するデバッグログを追加する。

## 意思決定内容
1. `SakuraAIClient::sendRealSakuraRequest` において、`m_networkManager->post` の直前に `qDebug().noquote() << "[SakuraAIClient] Request JSON:\n" << doc.toJson(QJsonDocument::Indented);` を追加。
2. ログファイル `tmp/app_debug.log` を見れば、`messages` 内に RAG 検索データが正しく組み込まれているかを 100% 可視化・確認できるようにする。
