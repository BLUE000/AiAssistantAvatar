# 意思決定記録: レートリミット管理専用タブ新設・動的項目UIモデル ＆ AI設定タブ制限項目廃止 (F-16-10) の仕様追加

## 実施日
2026-08-01 (18:36 JST)

## 理由・目的
- ユーザーがクリック操作なしで全プロバイダのレートリミット使用量・残枠を一目で監視できる「眺めるだけ（ノー・クリック）」専用タブを新設するため。
- プロバイダや API I/F ごとに提供される管理項目（RPM, RPD, TPM, Credit 等）が異なり、固定項目にすると曖昧な `N/A` / `-` 表示による混同や将来の I/F 変更への非対応が発生するため、「動的項目モデル (`RateLimitQuotaItem`) ＆ UI完全自動生成」アーキテクチャを採用するため。
- AI設定タブ内に配置されていた旧「プロバイダ制限設定」フォームを削除・撤廃し、UIレイアウトを一元整理・シンプル化するため。
