# AI アシスタントアバター (AiAssistantAvatar) 取扱説明書

このアプリは、Twitch（配信サイト）のチャットに届いたコメントをAIが読み取り、あなたに代わって自動で返答する**配信画面用のアバターアプリ**です。

AIの返答に合わせて、可愛いアバターの表情が変わり、画面上に吹き出し（字幕）がリアルタイムに表示されます。

---

## ✨ このソフトで出来ること（主な機能・特長）

* **🤖 コメントへの自動AI返答（Twitch ＆ Discord）**:
  Twitch の配信チャットや Discord サーバーに届いたコメントを AI が読み取り、あなたの代わりに即座に楽しく会話・返答します。
* **🎙️ マイク共有対応の音声入力（STT機能・2モード対応）**:
  * **マイク非独占（WASAPI/SAPI Shared）**: OBSやDiscordとのマイク共用に対応し、配信音声や通話を邪魔しません。
  * **ウェイクワード起動**: アバター名を呼ぶだけでマイクが反応し会話を開始します。
  * **プッシュ・トゥー・トーク (PTT)**: 「音声」ボタンを押している間だけマイク録音し、離すとAIへ自動送信します。
  * **別マシン（サブPC）動作**: アバターを別PCで動かすマルチPC配信環境や、ネットワーク経由の音声注入にも完全対応。
* **🎭 感情連動のアバター表情変化 ＆ 字幕表示**:

  AIの返答内容（嬉しい、怒り、困り顔等）に合わせてアバターの表情がダイナミックに変化。OBSに美しく透過字幕を表示できます。
* **🌐 最新Web情報のリアルタイム検索（Tavily / DDG）**:
  「今日のニュースは？」「最新のゲーム攻略は？」といった質問にも、リアルタイムにネット検索を行って正しく答えます。
* **📖 独自の知識を覚えさせる「ナレッジ機能」**:
  あなたのプロフィール、配信ルール、ゲーム用語などを自由に追加して、あなた専用のAIアシスタントに育てられます。
* **🎨 自由なイラスト差し替え＆吹き出しデザイン**:
  手持ちのイラストや自作画像にアバター立ち絵を差し替えたり、字幕のデザインを変更できます。

### 📊 各AIプロバイダの比較（無料枠の多さ ＆ 応答速度）

利用者の環境や用途（無料枠の多さ重視か、配信での即答速度重視か）に合わせて最適なプロバイダを選択するための比較表です。

#### 1. 無料利用枠の多い順（1日あたりの上限・余裕度）

| 順位 | プロバイダ / 主な無料モデル | 1日あたりの上限 (RPD) | 1分あたりの上限 (RPM) | 特徴・制限の余裕度 |
| :---: | :--- | :---: | :---: | :--- |
| **1位** | **Groq**<br>`llama-3.1-8b-instant` 等 | **14,400 回/日** | **30 回/分** | **圧倒的第1位**。配信中のコメント連打でもほぼ上限に達しない圧倒的な回数枠です。 |
| **2位** | **Gemini (Google AI Studio)**<br>`gemini-flash-latest` / `2.5-flash` | **1,500 回/日** | **15 回/分** | **第2位**。1日1,500回と非常に潤沢。数時間の配信なら余裕でカバー可能です。 |
| **3位** | **さくらAI (無料プラン)**<br>`Sakura LLM API` | **約 500〜1,000 回/日 相当**<br>(月間無料トークン枠) | **10〜20 回/分** | **第3位**。無料枠として十分なトークンが付与され、個人配信の規模であれば日常的に実用可能。 |
| **4位** | **OpenRouter**<br>`:free` タグ付きモデル | **約 200 回/日** | **20 回/分** | 1日200回制限。枠を使い切ると翌日リセットまで無料モデルは停止。 |
| **5位** | **Mistral AI**<br>`mistral-small` 等 | **検証/無料枠** | **1〜5 回/分** | 無料検証アカウントは RPM/月間枠が少なめで、長文対話が続くと制限に達しやすい。 |
| **6位** | **HuggingFace**<br>`Serverless Inference API` | **サーバー混雑依存** | **不定（変動）** | 共有クラスタのため混雑時は即座にレート制限（429）が発生しやすい。 |

#### 2. 応答速度の速い順（レイテンシ・生成開始の速さ）

| 順位 | プロバイダ / 主なモデル | 生成速度・レイテンシ | 体感レスポンス・解説 |
| :--- | :--- | :--- | :--- |
| **1位** | **Groq**<br>`llama-3.1-8b-instant` | **約 0.3 〜 0.6 秒**<br>(500〜800 tokens/sec) | **圧倒的最速**。専用LPUにより質問完了の瞬間に回答が返る超高速レスポンス。 |
| **2位** | **Gemini**<br>`gemini-flash-latest` / `2.5-flash` | **約 0.5 〜 1.0 秒** | **極めて高速**。Flash系モデルは超軽量で、プロンプトが長文でも安定して1秒未満で返答。 |
| **3位** | **さくらAI**<br>`Sakura LLM` (無料プラン) | **約 0.8 〜 1.5 秒** | **国内サーバー直結で低遅延**。日本国内リージョンのため回線往復（RTT）が極小で、安定して速い。 |
| **4位** | **Mistral AI**<br>`mistral-small` / `nemo` | **約 1.2 〜 2.0 秒** | **標準的**。海外サーバー経由ですが推論自体は軽快。 |

* **オートローテーション（安全機構）**:

#### 🧠 応用機能：Manager AI（2階層マルチエージェント）とは？

設定画面にある **「Manager AI（管理者AI）を有効化」** チェックボックスをオンにすると、2つのAIが連携して働く **先進的なマルチエージェントシステム** に切り替わります！

* **通常モード（OFF）**:
  コメントを受け取ると、選択したAIプロバイダが直接返答を作成します（シンプル＆高速）。
* **Manager AI モード（ON・推奨）**:
  * **司令塔（Manager AI）**: 裏で爆速AI（例: Groq等）が作動し、コメントの危険度チェック、Web検索が必要かの判定、**アバターの感情表現（笑顔、困り顔、驚き等）の判断** をミリ秒単位で瞬時に行います。
  * **アバター頭脳（Worker AI）**: 司令塔からの指示と感情指定を受け取って、キャラクターにぴったりな魅力的な返答と豊かな表情変化を作り出します。

> [!TIP]
> **おすすめの設定例**
> 司令塔（Manager AI）に爆速の `Groq` を設定し、アバター頭脳（Worker AI）にお好みの `Mistral AI` や `さくらAI` を設定すると、レスポンス速度と返答の賢さを両立した最高品質のアバター配信が可能になります！

* **Tavily キーの取得手順（Tavily API - 任意）**:
  AIに最新のネット検索を行わせるためのサービスです。空欄のままでも自動的に別の検索機能を使って賢く答えてくれますが、設定する場合は以下の手順で取得できます。
  - **ステップ①（プランの確認）**:
    まず [Tavily 料金プランページ](https://www.tavily.com/pricing) にアクセスし、利用可能なプランを確認します。
  - **ステップ②（ログイン）**:
    画面右上の「**Log in**」をクリックして、アカウント登録またはログインします。
  - **ステップ③（APIキーのコピー）**:
    ダッシュボード画面にAPIキーが自動で生成されています。キーの横にある**コピーボタン**（紙が2枚重なったようなアイコン）をクリックしてコピーし、本アプリの「**Tavily キー**」入力欄に貼り付けます。

### 2. Twitch（配信サイト）との連携設定
あなたの配信のチャットをAIが見に行けるようにします。
1. **Twitch チャンネル**：あなたのTwitchのユーザー名（ID）を入力します。
2. **アバター名**：アバター自身の名前（初期値は `AIアシスタント`）を設定できます。
3. **名前呼ばれて反応するか**：アバター名（例：「AIアシスタント」）をチャット内で呼ばれた際に、ウェイクワード無しでも自動的に反応して答えるかどうかの設定です。
4. **Twitch ウェイクワード**：AIが反応する「コマンドの合言葉」です（初期値は `!ai`）。チャットで `!ai こんにちは` のように話しかけるとAIが返答します。
5. **連携のやり方**：
   * チャンネル名などを入力して「設定を保存して適用」を押します。
   * その後、右下の「**Twitch認証開始**」ボタンを押します。
   * 自動的にブラウザが開き、Twitchのログイン画面が表示されます。ログインして「連携を許可」すれば準備完了です！

### 3. 音声入力（STT）の使い方（2つのモード ＆ マイク共有対応）
マイクに向かって声で話しかけることで、アバターと直接会話できます。他の配信・通話ソフト（OBS/Discord）のマイク利用を妨げない**「マイク共有アクセス仕様」**になっています。

* **モード①：ウェイクワード（アバター名）起動**
  * マイクを共有待機し、アバター名（例：「ぶるたろう」）を呼ぶと自動的にマイク認識がONになり、続く発話をAIに自動送信して会話を開始します。

* **モード②：プッシュ・トゥー・トーク (PTT) 音声ボタン長押し**
  * メイン画面の「**音声**」ボタンを押している間だけマイク録音（`🎤 録音中...`）が行われ、ボタンを離した瞬間に認識テキストが AI へダイレクト送信されます。
* **モード③：ブラウザ用 WebSTT 音声入力 ＆ ウェイクワード常時監視 Web 画面 (`http://<IP>:58082/stt`)**
  * スマホやサブPCのブラウザで `http://<IP>:58082/stt` を開くと、**マイク音声認識 ＆ ウェイクワード常時監視付き Web ページ**が表示されます。
  * スマホやブラウザのマイクから声で「ぶるたろう」やアバター名を呼ぶと、自動的に音声認識が作動してアプリへテキストが注入され、ハンズフリーでアバターと声で会話できます！

### 🗣️ 話者・対話コンテキスト管理機能 (誰が/誰に/発言種別の自動識別)
- **誰が誰に発言したかをAIが100%誤解なく理解**:
  - 発言者（配信者/視聴者/AI自身/システム）、宛先（AI宛て/配信者宛て/全体）、および発言種別（配信コメント/音声入力/AI回答）をメタデータタグとして構造化し、AI に送出します。
  - 「視聴者が配信者へ行った指摘を、呼びかけた人の問題だと勘違いする」「話しかけた人を別人と誤解する」といったハルシネーションを根本から防止します。

### 💬 応答コメントの500文字自動分割 ＆ スローモード対応送信（Twitch / Discord 共通）

Twitch や Discord のチャットで呼びかけられた際、AI が作成した回答テキストが **500文字を超える場合、自動的に文脈や句読点（`。` `！` `？` / 改行）を考慮して500文字以内のブロックに分割し、チャットへ送信**します。
* **500文字以下の返答**：1通のコメントとしてそのまま送信されます。
* **500文字を超える返答**：500文字以下の複数のブロックに綺麗に分割されます。
* **スローモード対応（安全送信キュー）**：分割された各メッセージは、チャンネルのスローモード（投稿間隔制限）やレートリミットに引っかからないよう、安全な送信インターバル（遅延キュー制御）を挟んで順次送信されます。
### 📊 AI レートリミット監視 ＆ 表示自動更新機能

* **レートリミットタブ**: ウィンドウ左側の「**レートリミット**」タブを開くことで、各 AI プロバイダ（Groq / Mistral / さくらAI / Hugging Face / OpenRouter）の 1 分間使用枠 (RPM) や利用可能ステータス（🟢 利用可能 / 🔴 レートリミット到達中）、リセットまでのカウントダウンをリアルタイム表示・更新できます。
* **表示更新呼びかけ対応**: チャットや音声入力で「**レートリミット表示して**」「**レートリミットの更新して**」とアバターに呼びかけると、最新ステータスを即時評価して「レートリミット」タブの表示を動的に更新し、利用枠・残量を回答案内します。

### 📝 `local_settings.json` での 1 行コメント (`#`) 対応
- 設定ファイル `local_settings.json` の中に `#` による1行コメントを直接記述できます。
- 行頭や設定項目の末尾に `# メモ文言` を書き込んでも、パース時に自動除去されて安全に読み込まれます。
  ```json
  {
    "ai_provider": "groq", # 主に使用するAI
    "groq_api_key": "gsk_...", # Groq APIキー
    "mistral_api_key": "..." # Mistral APIキー
  }
  ```

## 📺 配信画面（OBS）にアバターを映す手順

アバターと吹き出しをOBS Studio（配信ソフト）に表示させるのはとても簡単です。

1. **アプリの設定画面を開く**
   * 「OBS / 描画設定」の中にある「**OBS用ファイルパス**」の右側にある「**パスをコピー**」ボタンを押します。これで、必要なファイルの場所が自動的にコピーされます。

2. **OBS側の設定**
   * OBSを起動し、アバターを表示したいシーンの「**ソース**」欄にある「**＋**」ボタンを押し、「**ブラウザ**」を追加します。
   * プロパティ画面が表示されたら、「**ローカルファイル**」のチェックボックスを**オン（チェックを入れる）**にします。
   * 「参照」ボタンの横の入力欄に、先ほどコピーしたパスをそのまま貼り付け（Ctrl + V）ます。
   * アバターの大きさに合わせて、幅や高さを調整します（目安：幅 `400`、高さ `500` 程度）。
   * 「OK」を押して保存します。

3. **アバターアプリを起動する**
   * アプリを起動すると、OBSに貼り付けたアバターと吹き出しが自動的につながり、チャットの返答に合わせて動き出します！

## 📱/🖥️ ゲームの攻略情報やAIの回答を「文字だけ」手元で見る方法 (`http://<IP>:58082/ui_text`)

ゲーム中に声や文字でAIに「この攻略方法は？」「おすすめの選び方は？」と聞いたとき、**アバター画像を表示せず、AIの返答テキストだけを拡大して画面に表示する専用のWeb画面**が使えます！

Twitch配信画面のアバター字幕（`http://<IP>:58082/`）とは**別の独立したURL**になっているため、**「配信画面を邪魔せずに、手元のスマホやサブPCでゆっくり文字を読みたい」**という場面にぴったりです。

### 💡 使い方
1. **ブラウザを開く**:
   スマホやサブPC、タブレットのインターネットブラウザ（ChromeやSafariなど）を開きます。
2. **URLを入力**:
   アドレス欄に `http://<お使いのPCのIPアドレス>:58082/ui_text` と入力してアクセスします。
   *(※アプリを動かしているPCと同じWi-Fi・ローカルネットワーク(LAN)に接続されている端末から見ることができます)*
3. **文字だけの見やすい表示**:
   アバター絵のない暗めの背景（ダークモード）に、AIの返答テキストが大きく読みやすい文字でリアルタイム表示されます。
   *(※必要に応じて、このURLをOBSの「ブラウザ」ソースとして登録し、配信画面上にテキストだけを載せる使い方も自由に行えます)*

## 🛠️ 各種設定の見方・調整

よく使う便利な設定項目です。自分の配信のペースに合わせて自由に変更できます。

### 吹き出し表示秒数（OBS / 描画設定）
AIの返答（吹き出し）が画面に表示される時間を調整します。
* **次の要求がある時（初期値：5秒）**：
  リスナーから次々とコメントが届いてAIの返答が溜まっている時は、アバターがテキパキと次の返答に進むため、吹き出しを短め（5秒）で自動的に切り替えます。
* **次の要求が無い時（初期値：10秒）**：
  他に待っているコメントが無い時は、リスナーが最後の返答をゆっくり読めるように、吹き出しを長め（10秒）に表示したまま残します。

### WebSocket ポート (OBS用)（初期値：58081）
アバターの絵や文字をOBSに送り届けるための「専用の通り道（ポート）」の番号です。通常は変更しなくて大丈夫です。
もし他のソフトと番号が重なってしまって動かない場合のみ、適当な別の番号（例：`59000` など）に変更してください。
（※番号を変更して保存すると、OBS用のファイルも自動的にその番号に書き換わるため、OBS側を再設定する必要はありません）

### 外部通知設定 (WebHook)（通常は使いません）
アバターのセリフなどを、自作した別のプログラム（スマートホーム機器やDiscord通知など）に送るための上級者向けの機能です。
**単にアバターをOBSに映して配信したいだけの場合は、チェックを外して（OFFにして）おいて問題ありません。**

### 🛡️ 多層スコア判定・文脈保護フィルタリング（不適切発言ガード）
ゲーム配信や配信チャットの快適さを守るため、高度な多層スコア判定システムを搭載しています。

* **ゲーム話題・感情表現の誤ブロック防止**:
  - `blacklist.txt`（危険単語とスコア）と `whitelist.txt`（ゲーム名や「死ぬほど」等の感情表現による減算補正）を個別にカスタマイズ可能です。
  - 「Elinで薬物を売った」といったゲーム内の会話や日常の感情表現が誤ってブロックされるのを完全に防止します。
* **危険な教意思図の脱獄保護 (Jailbreak Guard)**:
  - 「作り方」や「個人情報」などの危険意図が検出された場合は過去の文脈補正が自動的に無効化され、AIの不適切な応答をブロックします。
* **政治・宗教・時事問題への中立応答インジェクション**:
  - 政治や宗教、敏感な時事話題が検出されると、リアルタイム検索を組み合わせつつ、AIに対して中立的・客観的立場を維持した配慮のある返答を自動で強制します。

## 🎨 アバタースキンの切替・自動生成機能

### 1. アバタースキンの選択（アプリ画面とOBSの完全同期）
* 「設定」タブ内の「**アバタースキン (Skin)**」プルダウンメニューから、お好きなスキン（例: `FishEatCatSkin` など）を選択するだけで、**本アプリの表示画面とOBS配信画面の双方が全く同じスキンへ自動的に一括切替**されます。

### 2. アバター演出と状態タイマー
* アバターの画像表示は、単一画像・ランダム抽選表示・パラパラアニメーション表示（コマ送り）に対応しています。
* チャット受信やマイク入力時には **Listening (聴取中)**、AI思考時には **Thinking (思考中)**、発声中には **Speaking (発話中)** へアバターが自動的に変化し、指定時間が経過すると自然に待機姿（Idle）へ復帰します。

### 3. アバタースキン自動生成・GUI編集ツール (`AvatarSkinBuilder.exe`)
自分だけのオリジナル画像から、ワンクリックで新しいアバタースキンを作成・登録できる独立ツールです！

* **起動方法**:
  - **方法A（本体アプリから起動）**: `AiAssistantAvatar.exe` の「設定」タブ内にある「アバタースキン」項目の隣の「**新規作成 / 編集...**」ボタンを押すと自動起動します。
  - **方法B（単体で直接起動）**: フォルダ内にある `AvatarSkinBuilder.exe` を直接ダブルクリックして単体で起動・利用することも可能です。

* **スキン作成・登録手順**:
  1. **スキン名の入力**: 作成したいスキン名（例: `MyCustomSkin`）を英数字で入力します。
  2. **画像と表示モードの割り当て**:
     - 正面・背面・右向き・左向き・聴取中・思考中・発話中の各状態タブを開きます。
     - 表示モード（単一 `single` / ランダム抽選 `random` / パラパラアニメ `sequence`）を選択します。
     - 「参照...」や「画像追加」ボタンを押して、手元の画像ファイル（PNG等）を指定します。
  3. **リアルタイムプレビュー ＆ インタラクティブ調整**:
     - 右側のプレビュー画面を見ながら、アンカー座標 (`anchorX/Y`) や透過基準点 (`transparentX/Y`)、コマ送り速度 (`frame_interval_ms`) を調整します。
  4. **「自動生成して保存」を押すだけ**:
     - `pic/MyCustomSkin/` ディレクトリの自動作成、画像の配置、`avatar_settings.json` および OBS表示用 `avatar_obs.html` の全自動生成が一瞬で完了します！
     - 保存後、本体アプリのスキン一覧プルダウンから新スキンを選択・適用するだけで配信で使用できるようになります。

## ❓ 動かないときのチェックリスト

* **OBS画面が真っ黒でアバターが映らない**
  * アバターアプリ本体が起動しているか確認してください。アプリが起動していないと、OBSに絵や文字が送られません。
  * OBSブラウザソースの設定で「ローカルファイル」にチェックが入っているか確認してください。
* **話しかけてもAIが返事をしてくれない**
  * 「設定」タブで「AI API キー」が正しく入力されているか確認してください。
  * チャットでの呼びかけの先頭に、設定したウェイクワード（`!ai` など）が付いているか確認してください（例: `!ai 今日の天気は？`）。
  * もしくは「名前呼ばれて反応するか」が有効な場合、アバター名（デフォルトは `AIアシスタント`）がメッセージ内に含まれているか確認してください（例: `AIアシスタント、今日の天気は？`）。

## 🛡️ ブラックリスト・ホワイトリストによる発言・入力フィルタリング

アバターが配信中に不適切な発言を行ったり、リスナーからの不適切なコメントに過剰に反応したりするのを防ぐため、入出力のフィルタリング機能が搭載されています。

これらの設定用テキストファイルは、実行バイナリ（`AiAssistantAvatar.exe`）と同じフォルダに配置して使用します。

### 1. ブラックリストの書き方 (`blacklist.txt`)
* **用途**: マスク（伏字化）したい不適切な単語（NGワード）を指定します。
* **記述ルール**:
  - **1行に1単語**ずつ記述します。
  - 大文字・小文字は区別されません（例: `baka` と記述すれば `Baka` や `BAKA` も対象になります）。
  - ブラックリストに該当する単語がユーザーコメント（入力）またはAIの返答（出力）に含まれていた場合、その単語は一律で **`****`** (4文字のアスタリスク) に置換され、マスクされます。
  - `#` から始まる行はコメント行として無視されます。空行も無視されます。

### 2. ホワイトリストの書き方 (`whitelist.txt`)
* **用途**: ブラックリストによる誤判定を防ぎ、例外的にマスクを免除したい感情表現や単語・フレーズ（例: `holy shit!`, `WTF`, 日本語の「`死ぬほど`」「`テロメア`」など）を指定します。
* **記述ルール**:
  - **1行に1単語または1フレーズ**（スペースを含む表現も可能）ずつ記述します。
  - 大文字・小文字は区別されず保護されます。
  - 単語の誤判定（例: ブラックリストに `ass` がある状態で、日常英単語 `class` の一部分が巻き添えで `cl****` になるなど）を防ぐために利用できます。
  - `#` から始まる行はコメント行として無視されます。空行も無視されます。
