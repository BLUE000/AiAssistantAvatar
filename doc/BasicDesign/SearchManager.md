# 基本設計書 - Web検索 ＆ RAG モジュール (SearchManager.md)

## 1. 概要
本モジュールは、AI の回答精度向上および最新情報提供を目的として、Web 検索（Tavily API および DuckDuckGo スクレイピング）およびローカルナレッジ（`MarkdownTableEngine`）から情報を抽出し、RAG（Retrieval-Augmented Generation）コンテキストを構成する。

Web 検索機能は、堅牢性・クラッシュ隔離・再利用性を確保するため、独立したコンソールアプリケーション（`WebSearcher.exe`）として分離・実装し、メインアプリケーション（`AiAssistantAvatar.exe`）および各種外部モジュールからプロセス間呼び出し（CLI/標準入出力連携）を行う構成とする。

## 3. Web 検索コンソールアプリ (`WebSearcher.exe`) 仕様

### 3.1 コマンドライン引数仕様

| 引数名 | 必須 / 任意 | デフォルト値 | 説明 |
| :--- | :---: | :---: | :--- |
| `--query`, `-q` | **必須** | - | 検索クエリ文字列（例: `"今日の大阪の天気"`） |
| `--tavily-key`, `-k` | 任意 | 空文字 | Tavily Search API キー（指定時、Tavily を優先実行） |
| `--timeout`, `-t` | 任意 | `5000` | 各検索エンジンの通信タイムアウト（ミリ秒） |
| `--help`, `-h` | 任意 | - | ヘルプメッセージを表示して終了 |

### 3.2 終了コード（リターンコード）仕様

| 終了コード | 状態 | 出力内容 (stdout / stderr) |
| :---: | :--- | :--- |
| `0` | **成功** | 標準出力（stdout）にクレンジング済み検索結果テキストを出力 |
| `1` | **検索失敗 / 不可** | 標準出力（stdout）に `Web検索不可: 検索結果を取得できませんでした。` を出力（stderr に詳細ログ） |
| `2` | **引数不正** | 標準エラー出力（stderr）に引数エラーメッセージを出力 |

### 3.3 フォールバックおよびタイムアウト制御フロー
1. `--tavily-key` が指定されている場合:
   - **Tavily Search API** へ HTTP リクエストを送信。
   - 指定タイムアウト（例: 5000ms）以内に 200 OK で正常取得できた場合 ➔ ノイズ除去を行い stdout に出力して終了（code 0）。
   - タイムアウト、HTTP 401/429/500、または通信エラーが発生した場合 ➔ サイレントに **DuckDuckGo スクレイピング** へフォールバック。
2. `--tavily-key` が未指定（空文字）の場合:
   - 直ちに **DuckDuckGo スクレイピング** を実行。
3. DuckDuckGo 検索処理:
   - 指定タイムアウト内に HTML を取得・パース・ノイズ除去できた場合 ➔ stdout に出力して終了（code 0）。
   - DuckDuckGo もタイムアウトまたはパース失敗した場合 ➔ `Web検索不可: 検索結果を取得できませんでした。` を出力して終了（code 1）。

## 4. メインアプリケーションからの呼び出し設計

- `AiAssistantAvatar.exe` は、`QProcess` を使用して `WebSearcher.exe` を非同期/同期実行する。
- 実行ファイルの検索順序:
  1. アプリケーション実行ディレクトリ（`QCoreApplication::applicationDirPath() + "/WebSearcher.exe"`）
  2. カレントディレクトリまたは `build/` ディレクトリ
- メインアプリ側で `QProcess` のタイムアウト（`WebSearcher.exe` のタイムアウト + 1000ms 程度のマージン）を設け、万が一のハングアップを防止する。

---

## 5. マークダウンナレッジエンジン (`MarkdownTableEngine`)

- ローカル Markdown ファイル群から、ユーザーの入力キーワードに合致するトリガーテーブルデータを高速抽出し、RAG コンテキストへ注入する。
- 独立フォルダ構造（`knowledge/Omikuji/`, `knowledge/Zodiac/` 等）を自動検出し、フォルダ単位での機能有効化・無効化をサポートする。
- プロンプトや Markdown 内に埋め込まれたマクロ式（`DailyTableSelect`, `TableSelectRandom`, `TableSearch`, `DailyRandom`, `Random`）およびプレースホルダー（`{Date}`, `{User}`）を事前評価・置換する。
