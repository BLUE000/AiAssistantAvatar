# 基本設計書 - 段階的タスク分解 ＆ 役割分離プロンプト構築 (PromptBuilder.md)

## 1. 概要
本モジュールは、ユーザーのプロンプト文を意図解析・タスク分解し、`User` ロールと `System` ロールを厳密に分離したプロンプト構造を構築するコンポーネントである (`F-16-9`)。

---

## 2. 主要機能 ＆ コンポーネント設計

### 2.1 Intent 判定最適化 (目的語限定トリガー)
- 単なる「今日」「明日」という日時キーワード単体での Web 検索自動発火を全廃。
- 「天気」「ニュース」「株価」「為替」「潮汐」などの明確な情報目的名詞が含まれる場合のみ Web 検索を発火させる。
- 「予定」「スケジュール」「タスク」「カレンダー」が含まれる場合は Web 検索を即座にスキップし、`TaskFlow` へ優先ルーティングする。

### 2.2 役割分離プロンプト構造 (Role Separation)
- `User` メッセージにはユーザーの発言本文（例: 「今日の予定は？」）のみを純粋に格納。
- 収集された事前データ（Web検索結果、TaskFlowデータ、ナレッジ等）はすべて `System` プロンプト領域（`systemInstruction`）へ `[事前収集リファレンスデータ]` として分離注入する。
