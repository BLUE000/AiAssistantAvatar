# OpenRouter アカウント作成・APIキー取得ガイド

OpenRouter（オープンルーター）は、世界中の様々な先進AIモデルを一つの統一APIキーで呼び出せるアグリゲーションサービスです。無料枠モデル（`:free` タグ付きモデル）が豊富に提供されているのが大きな特徴です。

---

## 🔑 APIキーの取得手順

### ステップ①：公式サイトへアクセス
[OpenRouter 公式サイト](https://openrouter.ai/) にアクセスします。

### ステップ②：ログイン / アカウント作成
右上の「**Sign In**」ボタンを押します。Googleアカウント、GitHubアカウント、またはメールアドレスで瞬時にアカウントを作成できます。

### ステップ③：API Keys 画面を開く
1. ログイン後、左側メニューの「**API Keys**」をクリックします。
2. 画面右上にある紫色の **`+ New Key`** ボタンを押します。

### ステップ④：キーの生成
1. **Name** 欄に分かりやすい名前（例: `Chatbot Key`）を入力します。
2. その他の項目（`Credit limit` や `Reset limit`）は一切触らず**空欄・N/AのままでOK**です。
3. 右下の **`Create`** ボタンを押します。

### ステップ⑤：キーのコピー
表示されたポップアップ画面内の **「Copy」** ボタンを押して、APIキー（`sk-or-v1-...` で始まる長い文字列）をコピーします。
※表示されたキーは画面を閉じると再確認できなくなります。

---

## 🛡️ 完全無料で安全に使うためのポイント
OpenRouter は事前チャージ（プリペイド）制です。クレジットカードを登録してチャージしない限り、**勝手に請求されることは 100% ありません**。

アプリ設定画面の「OpenRouter モデル」プルダウンで、語尾に **`:free`** とついた完全無料モデルを選択してお使いください：
* **`meta-llama/llama-3.1-8b-instruct:free`** (推奨・無料)
* **`google/gemma-2-9b-it:free`** (無料)
* **`mistralai/mistral-7b-instruct:free`** (無料)

---

## 💡 アプリ設定画面での指定
- **OpenRouter 使用**: チェックを入れる
- **OpenRouter API キー**: コピーした `sk-or-v1-...` キーを貼り付け
- **OpenRouter モデル**: プルダウンから `:free` のつくモデルを選択
