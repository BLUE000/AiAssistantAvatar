# Cerebras AI アカウント作成・APIキー取得ガイド

Cerebras AI（セレブラス AI）は、独自のウェハースケール巨大AIチップによる超高速な応答レスポンス（爆速生成）が特徴のAIプロバイダです。配信チャットのリアルタイムなテンポに最適です。

---

## 🔑 APIキーの取得手順

### ステップ①：公式サイトへアクセス
[Cerebras Inference 開発者ポータル](https://inference.cerebras.ai/) にアクセスします。

### ステップ②：アカウント登録・ログイン
画面内の「**Get Started**」または「**Sign In**」ボタンを押し、Googleアカウントやメールアドレスでアカウント登録（Sign Up）します。

### ステップ③：APIキーの作成
1. ダッシュボード画面の左側メニューまたは上部ナビゲーションから「**API Keys**」を開きます。
2. 「**Create New Key**」ボタンをクリックします。
3. キーの名前（例: `AiAvatar`）を入力して生成します。

### ステップ④：キーのコピー
生成された API キー（`csk-...` で始まる文字列）をコピーし、アプリの設定画面の **「Cerebras API キー」** 欄に貼り付けます。

---

## 💡 アプリ設定画面での指定
- **Cerebras AI 使用**: チェックを入れる
- **Cerebras API キー**: コピーしたキーを貼り付け
- **Cerebras モデル**: プルダウンから `llama3.1-8b (推奨)` またはお好みのモデルを選択
