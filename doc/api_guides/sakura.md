# さくらAI (さくらのAI Engine) アカウント作成・トークン取得ガイド

さくらAI（さくらのAI Engine Inference API）は、さくらインターネットが提供する高品質な国内クラウドAIサービスです。国立情報学研究所（NII）等の国産LLMモデルを含む豊富な最新モデルを安全な国内インフラで利用できます。

---

## 🔑 アカウントトークン（APIキー）の取得手順

### ステップ①：さくらのクラウドにサインアップ
[さくらのクラウド 会員登録/ログインページ](https://secure.sakura.ad.jp/cloud/) にアクセスし、さくらインターネット会員として登録・ログインします。

### ステップ②：さくらのAI Engine コントロールパネルを開く
1. さくらのクラウドコントロールパネルから「**さくらのAI Engine**」サービスを選択します。
2. 利用規約を確認し、サービスの利用を開始します。

### ステップ③：アカウントトークンの発行
1. コントロールパネルのメニューから「**アカウントトークン**」または「**APIキー管理**」を選択します。
2. 「**トークン作成**」ボタンを押します。
3. トークン名（例: `AiAvatarToken`）を設定し、生成を実行します。

### ステップ④：トークンのコピー
発行されたアカウントトークン（`<UUID>:<シークレット>` の形式の文字列）をそのままコピーし、アプリの設定画面の **「さくらAI API キー」** 欄に貼り付けます。

---

## 💡 アプリ設定画面での指定
- **さくらAI 使用**: チェックを入れる
- **さくらAI API キー**: コピーしたアカウントトークン（`<UUID>:<シークレット>`）を貼り付け
- **さくらAI モデル**: プルダウンから `llm-jp-3.1-8x13b-instruct4`（国産LLM・推奨）やお好みの最新モデルを選択

※アプリは自動的にさくらの公式正解エンドポイント `https://api.ai.sakura.ad.jp/v1/chat/completions` へ接続します。
