# Groq AI アカウント作成・APIキー取得ガイド

Groq AI（グロック AI）は、LPU（Language Processing Unit）による爆速な推論スピードと寛大な無料利用枠が魅力のAIプロバイダです。

---

## 🔑 APIキーの取得手順

### ステップ①：Groq Console へアクセス
[Groq Console](https://console.groq.com/) にアクセスします。

### ステップ②：アカウント登録・ログイン
GoogleアカウントやGitHubアカウント、またはメールアドレスを使用して無料でアカウントを作成します。

### ステップ③：APIキーの作成
1. 左側のサイドメニューから「**API Keys**」をクリックします。
2. 画面右上にある「**Create API Key**」ボタンを押します。
3. キーの名前（例: `AiAssistantAvatar`）を入力し、「**Submit**」をクリックします。

### ステップ④：キーのコピー
ポップアップ画面に表示された API キー（`gsk_...` で始まる長い文字列）をコピーし、アプリの設定画面の **「Groq API キー」** 欄に貼り付けます。
※キーは一度閉じると二度と表示されませんので必ずコピーしてください。

---

## 💡 アプリ設定画面での指定
- **Groq AI 使用**: チェックを入れる
- **Groq API キー**: コピーしたキーを貼り付け
- **Groq モデル**: プルダウンから `llama-3.3-70b-versatile (推奨)` を選択
