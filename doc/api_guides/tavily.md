# Tavily API アカウント作成・APIキー取得ガイド

Tavily（タビリー）は、AIがリアルタイムに最新のWeb情報やニュース、天気、攻略情報などを検索して回答に組み込めるようにするための **AI向けWeb検索拡張エンジン（RAG）** です。

※本キーの設定は任意です。空欄のままでもDuckDuckGo等の自動無料検索が機能しますが、Tavily キーを設定すると検索精度が格段に向上します。

---

## 🔑 APIキーの取得手順

### ステップ①：プランの確認
[Tavily 料金プランページ](https://www.tavily.com/pricing) にアクセスし、提供されているプラン（月1,000回まで無料の Free プラン等）を確認します。

### ステップ②：ログイン / アカウント作成
画面右上の「**Log in**」または「**Sign Up**」をクリックします。Googleアカウント、GitHubアカウント、またはメールアドレスで瞬時に無料アカウントを作成できます。

### ステップ③：APIキーのコピー
ログイン後、ダッシュボード画面（Overview / API Keys）に API キーが自動生成されています。
キーの横にある **コピーボタン**（紙が2枚重なったようなアイコン）をクリックしてコピーします。

---

## 💡 アプリ設定画面での指定
- **Tavily キー (任意)**: コピーした API キー（`tvly-...` で始まる文字列）を貼り付け
