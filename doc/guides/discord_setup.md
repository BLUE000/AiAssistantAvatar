# Discord ボット作成・サーバー招待・連携ガイド

本アプリ（AIアシスタントアバター）は、Twitch 配信チャットだけでなく、ご自身の **Discord サーバーのテキストチャンネル** に届いたメッセージをAIが自動で読み取り、AIアバターとして返答することができます。

このガイドでは、Discord Developer Portal でのボット作成から、サーバーへの招待、アプリ本体での設定手順までを分かりやすく解説します。

---

## 🛠️ ステップ①：Discord Developer Portal でボットを作成する

1. [Discord Developer Portal](https://discord.com/developers/applications) にアクセスし、ご自身の Discord アカウントでログインします。
2. 画面右上の **「New Application」** ボタンをクリックします。
3. 名前（例: `MyAiAvatar` や `AIアシスタント`）を入力し、利用規約にチェックを入れて **「Create」** をクリックします。
4. 左側のサイドメニューから **「Bot」** を選択します。
5. 「Build-A-Bot」項目にある **「Reset Token」** ボタンを押します（二段階認証を求められた場合は入力します）。
6. 表示された **Bot トークン（長い文字列）** の横にある **「Copy」** ボタンを押してコピーし、メモ帳等に一時保存しておきます。
   * ※この Bot トークンはパスワードと同じですので、他人に教えないでください。

---

## ⚠️ ステップ②：ボットのメッセージ読み取り権限を許可する（重要！）

※この設定を行わないと、Discord チャットに投稿された本文を AI が読むことができなくなります。

1. 引き続き「Bot」ページを下にスクロールし、**「Privileged Gateway Intents」** というセクションを探します。
2. **「MESSAGE CONTENT INTENT」** のスイッチを **ON（有効）** に切り替えます。
3. 画面下に表示される緑色の **「Save Changes」** ボタンをクリックして保存します。

---

## 📩 ステップ③：ボットを自分の Discord サーバーに招待する

1. 左側のサイドメニューから **「OAuth2」** ➔ **「URL Generator」** を選択します。
2. **SCOPES（スコープ）** 一覧の中から **`bot`** にチェックを入れます。
3. 下に表示される **BOT PERMISSIONS（権限）** で、以下の 3 つにチェックを入れます：
   * **`View Channels`**（チャンネルの閲覧）
   * **`Send Messages`**（メッセージの送信）
   * **`Read Message History`**（メッセージ履歴の閲覧）
4. ページの一番下に生成された **「GENERATED URL」** の **「Copy」** ボタンをクリックします。
5. コピーした URL を Web ブラウザの新しいタブに貼り付けて開きます。
6. 「サーバーに追加」画面が表示されたら、ボットを参加させたいご自身の Discord サーバーを選択し、**「はい」** ➔ **「認証」** を押して承認します。

---

## 📱 ステップ④：アプリ本体（AiAssistantAvatar）での設定

1. アプリを起動し、一番下の **「設定」** タブを開きます。
2. **「Discord 連携設定」** セクションを探します。
3. **「Discordボット連携を有効化」** にチェックを入れます。
4. **「ボット トークン」** 欄に、ステップ①でコピーした Bot トークンを貼り付けます。
5. **「接続チャンネル ID」** を指定します：
   * **チャンネル ID の取得方法**: Discord 上でボットに返答させたいテキストチャンネル名を右クリック ➔ **「チャンネル ID をコピー」** を選択します。
   * ※右クリックメニューに「IDをコピー」が出ない場合は、Discord の 設定 ➔ 高級 ➔ **「開発者モード」を ON** にしてください。
6. 「設定を保存して適用」を押せば設定完了です！チャット内で話しかけると AI アバターが返答します。
