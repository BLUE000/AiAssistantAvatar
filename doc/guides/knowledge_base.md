# ナレッジ（独自知識データベース・長期記憶）の追加・管理ガイド

本アプリには、AIに独自の知識や思い出を学習させる方法が **2種類** あります。
目的ややりやすさに応じて使い分けることができます。

---

## 💡 2つのナレッジ機能の違い（どっちを使えばいい？）

| ナレッジの種類 | 登録方法 | おすすめの用途 | 特徴 |
| :--- | :--- | :--- | :--- |
| **① チャット対話インポート** | チャットで `/open_folder` | 配信ルール、プロフィール、メモ書き、日記 | **【推奨・一番簡単】** 文章やメモを放り込むだけでAIが自動要約・分類して記憶します。 |
| **② データベース直置き** | `knowledge/` フォルダに配置 | ゲームの攻略データベース、用語辞典 | **【上級者用】** 表形式（テーブルデータ）の厳密な辞書ファイルをアプリ起動時に一括読み込みします。 |

---

## 📂 1. チャットから登録する（① 対話インポート：推奨）

メモ書きやプロフィールなどの文章を、AIに自動分類させて登録する最も簡単な方法です。

1. **コマンドを送信する**:
   * アプリのチャット入力欄で **`/open_folder`** と入力して送信（Enter）します。
2. **投入用フォルダが開く**:
   * 自動的にエクスプローラーでナレッジ投入用フォルダ（`log/knowledge_input`）が開きます。
3. **ファイルを配置する**:
   * 読み込ませたいテキストファイルや資料（`.md` や `.txt`）をそのフォルダの中に保存します。
4. **チャットで説明を入力して登録完了**:
   * アプリのチャット欄で **「ファイル名」** と **「そのファイルの説明」**（例: `profile.md 配信者のプロフィール情報`）を入力して送信すると、AI が自動的に内容を理解・要約してナレッジに登録します！

---

## 📁 2. フォルダに直接置く（② データベース直置き：上級者向け）

アプリのインストールディレクトリにある **`knowledge/`** フォルダにテキストや Markdown ファイル（`.md`）を直接入れておくだけで、アプリ起動時にデータベースとして自動読み込みされます。

* 表形式のデータ（ゲームアイテム一覧や用語辞書など）を固いデータとしてそのまま参照させたい場合に適しています。

#### ステップ3：反応するキーワード（トリガー）と優先度を指定する

Markdown ファイルの先頭に以下のように「反応するキーワード（トリガー）」や「優先度」を指定できます：

```markdown
# トリガー
- 今日の運勢
- 占い
- おみくじ

# 優先度
- 100

# 運勢データ
| 運勢 | 幸運のアイテム | ラッキーカラー | アドバイス |
| 大吉 | 金のコイン | ゴールド | 今日は最高の1日！思い切った挑戦をしてみよう！ |
| 中吉 | 温かい紅茶 | オレンジ | 努力が実を結ぶ日。周囲への感謝を忘れずに。 |
| 小吉 | お気に入りの本 | グリーン | 落ち着いて過ごせば吉。マイペースでいこう。 |
| 吉 | 新しいメモ帳 | ブルー | 新しい発見があるかも。身の回りを整理しよう。 |
| 末吉 | 観葉植物 | イエロー | 焦らずゆっくり進めば運気アップ！ |
```

#### 🎲 アバターの反応ルールと安心の診断機能：
1. **誤爆防止**: チャット内で「AIアシスタント、今日の運勢は？」のようにアバター名やコマンドとセットで呼びかけられた時のみ安全に発火します。
2. **優先度制御**: 他のファイルとキーワードが被った場合でも、設定された「優先度」が高い方が確実に実行されます。
3. **構文診断レポート**: 表の書き間違いや構文エラーがあるファイルは自動的に読み込みからスキップされ、アプリの「ナレッジ」タブ上にエラー理由と該当行数がレポート表示されます。

## 💬 3. 会話ベースでの自動追加・長期記憶機能

**特別な操作をしなくても、AIと普段通り会話するだけで自動的に記憶が蓄積されます！**

* **会話からの自動記憶（長期記憶アーカイブ）**:
  AIとの会話が積み重なると、AI Client Manager が会話履歴から「重要な内容」と「検索キーワード」を自動的に抽出し、ナレッジデータベースへ記憶として自動追加保存します。
* **記憶の自動呼び出し**:
  チャットで「前話したこと覚えてる？」「以前の会話で〜」などと話しかけると、AI が自動的に過去のナレッジを想起して返答に反映します。

## 🖥️ 3. アプリ画面（ナレッジタブ）での一覧確認・削除

本アプリの設定画面には **「ナレッジ」** タブが用意されています。

1. アプリの **「ナレッジ」** タブを開きます。
2. 登録された知識データ（自動記憶・コマンドインポート等）がテーブル形式で一覧表示されます（タイトル、概要、キーワード、登録日時、ID）。
3. 不要になった記憶やナレッジがある場合は、行を選択して **「選択したナレッジを削除」** を押せば一括削除できます！

---

## 📚 2. ナレッジファイルを追加する手順

1. アプリのインストールフォルダ内にある **`knowledge/`** フォルダを開きます。
2. 読み込ませたい情報が入ったテキストファイル（Markdown `.md` または テキスト `.txt`）を保存します。
   * 例: `profile.md` （プロフィールや好きなゲーム）
   * 例: `rules.md` （配信の注意事項や禁止事項）
   * 例: `game_tips.md` （現在プレイ中のゲーム用語や攻略法）

---

## 📝 3. ナレッジファイルの書き方のコツ

AIが正しく理解できるように、見出しと箇条書きでシンプルに書くのがコツです。

### 記述例 (`profile.md`):
```markdown
# 配信者プロフィール
- 名前: 配信者太郎（ご自身の配信名）
- メインで遊ぶゲーム: Apex Legends, Monster Hunter
- アバターの口調: 元気で明るい語尾（〜だよ！、〜ね！）

# 配信ルール
- 配信中の中傷やネタバレコメントはNG
- 初見さん歓迎の挨拶は「いらっしゃい！」
```

---

## 💡 4. AIによるナレッジの自動活用

1. 視聴者から「配信者の好きなゲームは？」等の質問が届きます。
2. AI が裏でナレッジデータベースを自動検索し、関連する知識を取り出します。
3. あなたの配信ルールやプロフィールに沿った正確な回答をAIが生成して返答します！
