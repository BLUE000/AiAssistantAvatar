# スキンエディタの使い方（アバター画像・表情カスタマイズガイド）

本アプリでは、付属のオリジナルアバターだけでなく、ご自身の **オリジナル画像（PNG / Live2D素材 / 透過イラスト等）** にアバターの立ち絵や表情を差し替えたり、字幕吹き出しのデザインを自由にカスタマイズすることができます。

---

## 🎨 1. アバター画像（立ち絵・表情）の変更手順

1. アプリの設定画面から **「スキン / 描画設定」** または **「スキンエディタ」** タブを開きます。
2. 変更したい表情スロットを選択します：
   * **通常（待機）**
   * **笑顔（Happy）**
   * **怒り（Angry）**
   * **悲しみ（Sad）**
   * **驚き（Surprised）**
   * **困り顔（Troubled）**
3. **「画像を試聴・選択」** ボタンを押し、お好みの画像ファイル（`.png` / `.jpg` / 透過推称）を指定します。
4. AIの会話内容や感情判定に合わせて、指定した表情画像が自動的に切り替わります！

---

## 💬 2. OBS 吹き出し（字幕）デザインの調整

配信画面上に表示される字幕吹き出しの背景色、フォントサイズ、枠線、文字色などを調整できます。

1. **フォントサイズ・書体**: 配信解像度に合わせて文字の大きさを変更できます。
2. **背景色・透明度**: 配信画面の雰囲気に合わせて吹き出しの透明感やグラデーションを変更できます。
3. **位置と表示アニメーション**: 表示速度やフェードイン効果を調整できます。

設定を変更したら **「設定を保存して適用」** を押せば、OBS 側の表示もリアルタイムに更新されます！
